# 首版範圍與後續規劃

更新日期：2026-09-21。

## 0.7.1 Fade 拖曳即時顯示

- 按住左鍵拖曳 Fade 點時，控制點與曲線即時跟隨，不必等待放開；包含 30 px 收折軌道、縮放與水平捲動。
- 軌道線形使用與預覽／匯出相同的曲線計算，顯示預設、自訂及切割保留的曲線區間。
- 拖曳期間不修改專案、不重建影音預覽；放開一次套用並可一次復原，Esc 或失去滑鼠擷取還原。
- 切割沿用既有 Ctrl+B：選取片段，再把播放頭定位至欲切割處。

## 0.7 純音訊即時預覽

- 隔離重現長 PCM WAV 在 WPF `ScrubbingEnabled=true` 冷啟動時無法收到 MediaOpened 的逾時；純音訊改走 WinMM PCM 輸出，完全避開該開啟流程。
- 重用來源快取即時混音，四個 40 ms 區塊；音量／Fade／剪輯修改不再製作整首混音檔。
- 裝置取樣時鐘控制播放頭，切割沿用連續取樣與 Fade；精確暫停／定位、MUTE、EOF、復原／重做與空白鍵共同驗證。
- 新增獨立新程序的 245 秒 MP3 冷啟動測試、實際音訊裝置生命週期測試，以及混音與匯出內容比較。預覽階段及錯誤寫入有界本地診斷記錄。

## 0.6 預覽快取重用

- 預覽涵蓋零秒到結尾，前後定位與重播不再超出快取；停止／定位不取消正在完成的預載入。
- 純音訊改用 PCM WAV，省去黑畫面影片編碼；音訊來源完整解碼後有界暫存，後續編輯重用。
- 以實際影音內容及來源檔案狀態辨識快取；改名、鎖定、空軌與無 Fade 的連續音訊切割保留播放。
- 最近四份混音可供復原／重做重用；音量、Fade、MUTE 等真實內容修改仍需更新混音。
- 新增快取命中／淘汰／來源更新、原生音訊播放、前後定位／EOF 重播、待播操作與切割音訊一致性驗證。

## 0.5.1 時間尺快捷鍵修正

- 修正 TSF／IME 將 Space 標成 `Key.ImeProcessed` 後，時間尺快捷鍵忽略該事件的問題。
- 自訂時間尺／軌道與預覽操作區停用 IME；文字欄位保留中文輸入。
- 新增 IME 包裝按鍵的事件路由與原生播放回歸，修正前可重現失敗，修正後驗證播放時鐘前進與再次暫停。

## 0.5 連續音訊與精簡軌道

- 時間尺／預覽滑桿操作後空白鍵可播放／暫停；準備中的播放意圖不再被忽略。
- 最小縮放依可視軌道與專案長度調整，完整素材範圍可縮至 25% 或更小。
- 每軌獨立收折至 30 px，保留縮小編輯視圖與操作；音軌直接提供 MUTE。
- 同來源音訊共用解碼與重取樣，以音訊取樣座標切片，驗證切割前後 PCM 內容及 MP3／AAC 輸出。
- 連續預覽改為先準備播放頭至結尾的單一快取，移除每 20 秒換段的等待；長專案需較長初始準備與更多暫存空間。

## 0.4 操作便利更新

在 0.3 基礎上完成：

- 空白區拖曳框選、Ctrl 追加、Esc 取消；支援多軌與捲動座標，排除鎖定組。
- 群組與連動片段跨軌移動、整組落點預覽，時間差與相容軌道相對順序保持一致；整組驗證與一次復原。
- 逐格、前後一秒、片段邊界、選取起訖、精確時間、顯示整條時間軸。
- 吸附開關、Alt 暫時停用、群組所有片段頭尾吸附。
- 軌道右鍵操作、剪下與同軌波紋刪除快捷鍵。

## 0.3 輕量剪輯基礎

這版完成「匯入 → 多軌基本編輯 → 預覽 → 儲存／復原 → 匯出 MP4／MP3」的日常工作流程。沿用使用者允許限縮格式與功能的方向。

- 多軌新增／排序／刪除、素材拖放、邊界吸附、來源範圍修剪、圖片延長、切割與刪除。
- Ctrl+點選多選、複製／貼上／複製至尾端、同軌波紋刪除、影音分離及連動移動／修剪／切割／刪除。所有操作可復原／重做。
- 片段／軌道音量、靜音／隱藏、鎖定。音訊分離後原影片聲音停用，避免重複混音。
- Fade 把手、秒數、五種預設與兩個強度控制點的自訂曲線；獨立音訊 Fade、透明淡化／淡黑；切在 Fade 內保持曲線連續。
- 單張影片／圖片概覽、來源音訊波形，背景生成且不阻塞拖曳。
- 拖曳定位自動產生合成畫面；播放時從播放頭準備最多 20 秒，播完自動準備下一段。
- 專案存取、每 30 秒未存變更備份、異常退出後復原、遺失素材重新連結。
- 專案尺寸／幀率、MP4 畫質、MP3／AAC 位元率、完整或指定秒數區間匯出、進度及取消。
- 面板／名稱欄大小可調與版面記憶，Ctrl+滾輪以游標位置縮放時間軸。

這是可操作的輕量首版，並非成熟的即時多軌播放器。0.6 以整條時間軸及來源解碼快取取代上述分段方式；長影片與大量軌道仍需更多實際專案驗收。

## 後續項目

1. 即時影片合成、逐步來源解碼、代理素材、播放預取、長片與大量軌道效能驗收。
2. 全軌波紋編輯、更多對齊選項、快捷鍵自訂與真人操作手感驗收。
3. 可拖曳的完整貝茲曲線編輯器（目前固定時間控制點）、交叉轉場。
4. 即時音量表、監聽／獨奏、更多圖片構圖控制。
5. 安裝包／可攜式發佈與進一步相容性測試。
6. 視需求擴充格式、字幕、變速、降噪等。

## 時間估算

先前的「可操作原型約 1–3 個工作天、精簡實用首版約 2–4 週（預留 4–8 週）」是工程投入估算，非交付保證。這次以限縮輸入格式、背景波形與分段預覽完成輕量版本；即時播放與長片穩定度須獨立評估。

## 驗收與 Git

Release 建置、核心行為、WPF 真實匯入／批次編輯／復原／原生預覽、存檔重開、實際 MP4／MP3 影音內容／時長／輸出區間及來源保護檢查，並查看四種尺寸的版面圖。通過後檢查 diff、commit／push origin/main，不 force push。工具鏈、素材、快取、使用者專案及輸出檔不推送。
