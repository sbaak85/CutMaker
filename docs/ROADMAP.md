# 原型範圍與後續規劃

更新日期：2026-09-20。

## 0.2 可操作原型

本輪目標為「匯入 → 基本編輯 → 預覽 → 儲存重開 → 匯出 MP4／MP3」的完整流程。使用者允許先減少功能與格式支援；完成並驗證後推送既有 GitHub 儲存庫。

本輪提供：

- 多軌、素材拖放、移動與吸附、非破壞性頭尾修剪、切割、刪除。
- 最多 100 步復原／重做、片段／軌道音量、靜音／隱藏與鎖定。
- 片段頭尾 Fade 把手、秒數和五種預設曲線。
- 共同媒體合成流程產生預覽及輸出；原生播放器播放、暫停、拖軸定位。
- JSON 專案存取、來源路徑保留、MP4／MP3 完整時間軸輸出、進度及取消。
- 面板／名稱欄大小可調與版面記憶。

預覽先完成快取再播放；每次剪輯後按「更新預覽」。這個折衷讓首個原型可真正完成剪輯與輸出，但不代表已具備即時多軌播放器的效能。

## 尚待後續

1. 即時預覽、快速逐格定位、代理素材、波形與縮圖；長片及多軌壓力測試。
2. 多選、漣漪剪輯、影音拆分與連動、片段複製。
3. Fade 內切割的完整曲線繼承、自由貝茲曲線、獨立音訊／透明度／淡黑效果。
4. 自動儲存／復原、遺失素材重新連結、圖片時長、專案尺寸與匯出品質 UI。
5. 音量表、區間輸出、安裝／可攜式發佈。
6. 視需求擴充格式、字幕、變速、降噪等。

## 時間估算

先前的「可操作原型約 1–3 個工作天、精簡實用首版約 2–4 週（預留 4–8 週）」是工程投入估算，非交付保證。這次透過預先合成預覽、限縮格式與操作範圍，優先完成可操作原型。後續真正即時預覽與長片穩定度仍須獨立評估，不以本輪完成原型推算成熟產品工期。

## 基本版驗收與 Git

通過核心行為、WPF 匯入／編輯／原生預覽、存檔重開、實際 MP4／MP3 影音內容／時長及來源保護檢查後，檢查 diff 並 commit／push `origin/main`。沿用遠端歷史，不 force push；`.tools/`、素材、快取、使用者專案及輸出檔不推送。
