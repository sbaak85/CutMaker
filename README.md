# CutMaker

Windows 本機影片／音訊剪輯器。**0.8.0 加入局部波形、長音訊漸進載入、影片區間快取、預覽品質與快取管理，以及精細拖曳、接點試聽、Fade 預設和專案視圖記憶。保留非破壞性剪輯與 MP4／MP3 匯出。**

## 開始使用

在 `I:\Codex\工具型\CutMaker\` 雙擊 `啟動CutMaker.cmd`。

1. 把 MP4、MP3、WAV、PNG 或 JPG／JPEG 從檔案總管拖進素材庫，也可按「匯入素材」。
2. 把素材名稱拖到時間軸：影片／圖片放影片軌，音訊放音訊軌。可自由新增軌道。
3. 拖片段中央移動，拖兩端修剪；上緣金色方塊調整 Fade 長度，按住左鍵就能看到控制點與曲線變化，放開套用，Esc 取消。圖片可以延長超過預設的 5 秒。
4. 點時間尺定位，選片段後 B 切割。Delete 刪除；Ctrl+Z 復原、Ctrl+Y 重做。
5. 右側輸入起點、來源起點、長度、音量、Fade 秒數及曲線，再按「套用片段設定」。音量 100% 為原音量。
6. 拖時間尺／預覽滑桿定位。按「播放」或空白鍵，純音訊載入來源快取後直接即時混音播放；影片首次準備整條時間軸快取。再按空白鍵暫停，前後定位和重播可直接重用。
7. Ctrl+S 儲存 `.cutmaker` 專案。「匯出 MP4／MP3」先選畫面、畫質與區間，再選目的檔及格式。

所有剪輯均保留原始素材。同一素材可重複使用；專案記錄來源路徑，不內嵌媒體檔。

## 常用操作

| 操作 | 使用方式 |
| --- | --- |
| 框選／多選／全選 | Ctrl+左鍵從時間軸空白處重新框選；Ctrl+Shift+拖曳追加；Ctrl+點選追加；時間軸內 Ctrl+A |
| 取消選取 | Esc；空白處拖曳保留選取並定位播放頭 |
| 剪下／複製／貼上 | Ctrl+X／Ctrl+C；移動播放頭後 Ctrl+V，或軌道右鍵選單 |
| 複製至尾端 | Ctrl+D，保留選取片段的相對間距與原軌道 |
| 群組跨軌移動 | 拖選取片段中央，所有片段保留時間差，按影片／音訊軌各自的順序同步移動；半透明框顯示整組落點 |
| 波紋刪除 | Shift+Delete 或「編輯 → 同軌波紋刪除」，同軌後方片段前移刪除長度 |
| 音訊分離 | 選影片片段 →「編輯 → 分離音訊並連動」；原影片音訊停用，新增連動音軌 |
| 連動 | 移動、修剪、切割、刪除同步作用於連動片段；可從「編輯」解除連動 |
| 軌道設定 | 點軌道名稱，右側調整音量、靜音／隱藏、鎖定、上移／下移或刪除 |
| 軌道收折 | 點軌道左上角 ▾／▸，切換正常與 30 px 單行高度；收折後仍可編輯並查看縮小波形、邊界與 Fade |
| 音軌靜音 | 音軌上的 MUTE 切換靜音；醒目狀態表示已靜音，影響預覽、播放與匯出，可復原並存入專案 |
| 時間軸比例 | 軌道或時間尺上 Ctrl+滾輪，以游標時間為中心縮放；最小可讓整段占可視軌道 25%，極短專案可更小 |
| 播放／暫停 | 空白鍵；拖時間尺或預覽滑桿後仍有效。預覽準備中可切換完成後是否自動播放；文字欄位維持正常輸入 |
| 顯示全部 | Ctrl+0 或「編輯 → 顯示整條時間軸」，將完整專案縮放到視窗內 |
| 逐格／逐秒 | A／D 或 ←／→ 前後一格；Shift+←／→ 前後一秒；預覽區也有逐格按鈕 |
| 快速定位 | Alt+←／→ 跳到前後片段邊界；Home／End 到時間軸起訖；右鍵可到選取範圍起訖 |
| 精確時間 | Ctrl+G，輸入秒數、分:秒或時:分:秒，例如 01:12.5 |
| 吸附控制 | C 切換邊界吸附；拖曳時按住 Alt 暫停吸附；停用後仍以專案幀率對齊 |
| 備份復原 | 未存變更每 30 秒備份；下次啟動提示可復原項目，或按「備份復原」 |
| 重新連結 | 素材庫選素材 →「重新連結」，保留現有剪輯範圍與素材 ID |

片段剪下／複製／貼上／全選及吸附快捷鍵在時間軸焦點下生效，定位快捷鍵也可在預覽區使用；文字欄位維持一般文字編輯。最多保留 100 步復原／重做；換專案會清除歷史與內部剪貼簿。

時間尺、軌道與預覽操作區停用輸入法處理，避免拖曳後的空白鍵被中文輸入法接走；快捷鍵也辨識輸入法包裝的按鍵事件。專案名稱等文字欄位仍可正常輸入中文。

框選會包含連動夥伴；鎖定軌道上的片段，以及含有鎖定夥伴的連動組，會略過。群組跨軌例子：影片一移到影片二時，連動的音訊一也移到音訊二。若任何成員缺少對應軌道、目標被鎖定或會重疊，整組不移動並顯示原因。框選與定位不會增加復原步驟，群組移動只需一次 Ctrl+Z 即可復原。

## Fade、波形與預覽

- 五種曲線：線性、慢進、慢出、平滑 S、等功率；「自訂曲線」可設定兩個 0–1 強度控制點，時間位置固定為 1/3 與 2/3。
- 正常與收折軌道都會畫出所選 Fade 曲線；拖曳中只更新曲線與控制點，放開後才套用影音效果並記錄一次復原。Esc 或失去滑鼠擷取會取消未套用的變更。
- 「進階 Fade／獨立音訊」可讓聲音使用自己的 Fade；畫面可選透明淡化（露出下層）或淡黑（仍遮住下層）。
- Fade 中間可以切割，兩段沿用原曲線區間；修改 Fade 長度或曲線會建立新的完整曲線。一般頭尾修剪將 Fade 重新放到外側邊緣並限制長度。
- 上方影片軌在前景；隱藏影片軌也會靜音。影片原音和音軌混合，分離音訊後不會重複混音。
- 背景產生單張素材縮圖與真實音訊波形。波形隨來源修剪對齊，代表來源聲音，未套用增益與 Fade。
- 拖曳停止約 110 毫秒後開始產生該位置的合成畫面，實際完成時間取決於解碼；快速拖曳會取消舊工作。
- 播放快取涵蓋整條時間軸，前後定位、停止、播完重播和再次按「更新預覽」都會重用。準備中定位或停止只取消待播，不丟棄處理進度；「取消」才中止準備。
- 純音訊專案使用原生 48 kHz 立體聲 PCM 裝置，四個 40 毫秒緩衝區持續即時混音；不產生整首混音 WAV、不等待影片元件開啟。播放位置所需資料就緒後，定位、音量／Fade 修改與復原可重用來源建立混音設定。
- 影片預覽可選最高寬 480／960／1280，最高 30 fps；約每 10 秒建立可重用畫面區間，修改後只重算受影響區間，再搭配完整連續音訊合成單一播放檔。大型影片可選擇建立代理，匯出仍使用原始素材。首次影片準備、音訊重算及最後合併仍需等候。
- 重新命名、鎖定、加空軌與不含 Fade 的連續音訊切割不清掉預覽。影片保留最近四份快取（512 MiB 軟上限，單份超過仍保留），復原／重做後播放可重用；關閉視窗清除本次影片快取。
- 同來源切割片段共用音訊解碼與重取樣，以一致的音訊取樣座標處理接點；切割不加入空白、重複聲音或新的淡入淡出。既有 Fade 曲線保持連續。
- 音訊來源解碼到磁碟快取，後續剪輯重用。超過 300 秒且容量足夠的來源，在播放位置附近資料就緒後可開始播放，剩餘資料持續載入；深處定位需等解碼追上。解碼仍從來源零點開始以保持重取樣相位；未就緒時暫停裝置時鐘，不用靜音替代缺少的取樣。
- 「預覽與快取」可查看用量、清除未使用快取及設定 1–32 GiB，預設 4 GiB。完成的來源音訊、波形、影片區間與代理可跨次啟動重用。使用中的檔案不刪除，所以容量是軟上限；另有工作階段完整播放檔與最多 2 GiB 的來源範圍暫存。來源路徑、大小或修改時間變更會使對應快取失效。
- 即時音訊使用確定性的 95% 峰值限幅；一般未過載音訊與匯出保持相同剪輯／Fade，過載時與匯出的前視限制器會有聽感差異。避免將多軌總音量推到失真範圍。

軌道收折、面板大小、時間軸比例與位置、播放頭會依已儲存專案路徑記憶，不增加復原步驟。純音訊播放中調整音量／MUTE 會沿用裝置與來源快取，以 5 ms 增益斜坡切換；既有裝置緩衝帶來最多約 160 ms 的反應延遲。其他剪輯及含影片專案的音量修改會更新預覽。

## 儲存、復原與匯出

專案保存剪輯、軌道、效果、連動與畫面設定。自動備份是獨立的工作復原檔，不覆蓋專案；異常退出後可恢復為尚未儲存的副本。正常儲存、同意放棄變更或關閉時會清理該工作階段的備份。其他仍開啟的 CutMaker 視窗不會被當成待復原工作。

來源遺失時仍能開啟專案，素材庫會標示「找不到檔案」。重新連結須為相同媒體類型，影音時長要足以覆蓋所有既有片段。

輸出設定提供橫向 1080p／720p、直向 1080p、方形 1080p，以及 24／25／30／60 fps。尺寸與幀率會存入專案；畫質、音訊位元率與輸出區間僅適用本次工作階段。

- MP4：H.264＋AAC；較小檔案／平衡／高畫質。
- MP3：128／192／256／320 kbps；預設 192 kbps。MP4 音訊也使用選定的位元率。
- 整條時間軸或指定起訖秒數，包含空白與靜音；區間輸出從 0 秒開始。
- 匯出使用開始時的專案快照，過程可繼續編輯。取消／失敗保留既有目的檔，禁止覆蓋來源素材或專案。

## 目前限制

- 輸入限 MP4、MP3、WAV、PNG、JPEG；影音匯入須可由 Windows 媒體元件讀取。主要驗證 H.264／AAC MP4、MP3、PCM WAV。
- 同一軌道不允許片段重疊，多軌可以。跨軌移動需事先存在足夠的相容軌道；尚無全軌波紋編輯。會破壞連動同步的同軌波紋刪除會拒絕。
- 波形固定 1024 個峰值，縮圖是素材概覽，沒有逐格縮圖帶；超長素材背景波形有逾時限制。
- 尚無即時影片合成、代理管理、音量表、字幕、變速、降噪、交叉轉場及完整自由貝茲編輯器。
- 自動化驗證不代表已完成真人滑鼠手感、所有媒體編碼或長片／大量軌道的壓力驗收。

## 工具與驗證

使用專案本地 .NET SDK 10 與 FFmpeg，無第三方 NuGet 套件、不安裝系統解碼器包、不修改 PATH。新電腦在 PowerShell 執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-ffmpeg.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

下載版本、驗證及授權文件見 [DEPENDENCIES](docs/DEPENDENCIES.md)。工具鏈、個人素材、快取、專案和匯出檔不納入 Git。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

包含 Release 建置、核心檢查、離屏 WPF 真實匯入／編輯／框選／跨軌群組操作／吸附／逐格定位／復原／重新連結／波形／原生播放、四種尺寸的版面圖，以及 FFmpeg 真正的 MP4／MP3 內容驗證。結果在 `runtime/verification/smoke/` 與 `runtime/render-checks/`。

## 時間軸視覺與操作更新

- 素材片段採深金色直角細框，頭尾各 30% 向中央漸暗，左上／右下框線高亮；概覽與局部波形皆為金色。
- 尺規可操作高度為 42 DIP。尺規、軌道空白、軌道間隔與下方空白可左鍵拖曳定位，保留素材選取；Ctrl+左鍵從空白處拖曳為重新框選，Ctrl+Shift+拖曳才追加。
- 時間軸取得焦點時，B 切割；[ 將選取片段開頭修剪至播放頭，] 修剪結尾。括號只縮短、不新增片段，播放頭必須在片段內部；連動與锁定限制沿用既有規則，可一次復原。Ctrl+B 已停用，文字欄位保留正常輸入。
W／S 定位目前主選素材開頭／結尾；C 切換吸附，在播放頭旁提示 1 秒後以 0.2 秒淡出。Ctrl+C／Ctrl+S 等原有組合键保留。
